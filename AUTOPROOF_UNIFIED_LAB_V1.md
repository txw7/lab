# AutoProof unified Lab tranche V1

This tranche installs the Lab-owned semantic seam for the unified research proof stack

## Ownership

Lab owns mathematical IR, theorem-domain adaptation, formal projection, provider declarations, checked evidence adaptation, and domain counterexample extraction

LSIP remains the generic search authority, ResearchGraph remains durable research authority, Neu remains runtime orchestration and Canon authority

## Systems

`formal/math/` defines the scientific mathematics IR, Research wire mapping, projection-law registry, provider registry, and MathSearchFormalBridgeV1

`theorem-workbench/` defines the generic theorem target and domain-adapter layer, its topology compatibility adapter deliberately preserves bounded witness and bounded obstruction semantics rather than promoting those artifacts to unrestricted theorem status

`rh-workbench/` defines the Gaussian-Weil first-contact target, representation catalog, RH operator catalog, ActiveRHFrontierV1 import seam, and FORMAL projection boundary

## Deliberate exclusions

This tranche does not add a frontier, population, scheduler, quotient archive, fitness engine, generic repair loop, durable research graph, or second proof checker

Declared providers without a bound executor report capability-missing, unsupported mathematical projections remain open

## Local gate

Run

`bash scripts/check-autoproof-unified-lab-v1.sh`

The gate loads the existing FORMAL system plus the three new systems, runs focused FORMAL regressions and the new seam tests, builds the Lab Lean project, and runs the simulation crate tests

The active RH Lean project in txw7/research has a different pinned Lean and Mathlib environment, it remains a separate external formal provider until a deliberate toolchain convergence is performed
